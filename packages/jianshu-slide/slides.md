# 简书是什么

2013 上线的中文综合写作平台

- **综合写作**：技术、散文、读书、生活共存
- **Markdown 友好**：早期卖点，对程序员友好
- **页面简洁**：相比 CSDN / 公众号广告少
- **门槛低**：注册即写，免费开放访问
- **专题合集**：投稿到他人 / 官方专题获曝光

> 技术写作只是其内容的一个子集，近年明显衰退

# 平台对比

| 维度 | 简书 | 掘金 | CSDN |
|---|---|---|---|
| 定位 | 综合写作 | 纯技术垂直 | 博客聚合 |
| 上线 | 2013 | 2015 | 1999 |
| 技术浓度 | 中（子集） | 极高 | 高（搬运多） |

| 现状 | **衰退** | 增长 | 稳定 |

> 曾是优质中文长文社区，技术内容已边缘化

# 写第一篇文章

「写文章」→ 编辑器（Markdown / 富文本）

**文章结构**

- 标题：含关键词
- 封面：单图或多图
- 正文：Markdown / 富文本
- 标签 / 专题：投稿获曝光
- 摘要：自动或手填

**编辑器**

- Markdown：程序员友好，代码块
- 富文本：所见即所得，非技术友好

注册：手机号 / 微信 / 微博 / QQ

::right::

# 专题（合集）

核心分发手段之一

| 类型 | 示例 |
|---|---|
| 官方专题 | IT 技术 / 读书 / 散文 |
| 个人专题 | 用户自建 |
| 投稿专题 | 接受投稿，编辑审核 |

**投稿流程**

1. 浏览专题广场
2. 发文时选「投稿到专题」
3. 等待编辑审核
4. 通过后显示在专题页

> 投稿是简书主要的额外曝光途径

# 简书钻 / 简书贝

曾推出的代币激励机制（效果有限）

- **简书钻**：衡量用户「权重」，持有越多点赞权重越大
- **简书贝**：可交易的代币
- 持有简书钻可获文章收益分成

**现状**

- 代币机制未解决流量与商业化核心问题
- 变现能力有限，难留优质创作者
- 持续运营但热度下降

> 不要依赖简书钻变现，收益低

# 衰退的三重原因

首页中心化 + 综合稀释 + 商业化乏力形成恶性循环

| 原因 | 表现 | 后果 |
|---|---|---|
| 流量不公 | 首页占 80%，无个性化算法 | 新人曝光难 |
| 质量下滑 | 开放免费致注水 | 优质被淹没 |
| 商业失败 | 简书钻效果有限 | 头部流失 |

**恶性循环**

- 流量集中首页 → 新人曝光难 → 创作者流失
- 内容质量下滑 → 读者流失 → 流量进一步下降
- 商业化乏力 → 无资源激励 → 头部创作者流失

> 技术类创作者大量迁移到掘金 / 知乎 / CSDN / 公众号

# 退出还是留守

技术写作者的决策权衡

**完全退出（推荐）**

- 新写作者：直接去掘金 / 知乎
- 追求流量 / 变现：掘金算法 + 小册更友好

**操作**

1. 导出历史文章（Settings → 导出）
2. 在掘金 / 知乎重新发布
3. 简书原文设 canonical 指向新地址
4. 简书主页留引流链接

::right::

# 历史文章迁移

**迁移步骤**

1. 导出：Settings → 导出 Markdown
2. 整理：检查格式、图片链接
3. 选新平台：个人博客 / 掘金 / 知乎 / CSDN
4. canonical 声明：新平台设原文 URL
5. 更新简书原文顶部加迁移引流

**图片防盗链处理**

- 简书图片外链会 403
- 重新上传到新平台 CDN
- 用图床（GitHub / 阿里云 OSS）

> 简书作为多平台分发一环（非主阵地）

# 简书的遗留价值

尽管衰退，仍有少量遗留价值

| 价值 | 说明 |
|---|---|
| 老文章 SEO 长尾 | 部分老文章仍获搜索流量 |
| Markdown 练习场 | 新手练写作的入门平台 |
| 历史归档 | 早期内容沉淀的记录 |

**创作者迁移去向**

- **掘金**：字节流量 + 算法推荐 + 技术垂直
- **知乎专栏**：综合流量 + 关注机制
- **CSDN/公众号**：SEO 流量 / 私域变现

> 简书作为多平台分发的一环（非主阵地）
