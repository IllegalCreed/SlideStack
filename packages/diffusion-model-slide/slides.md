# 扩散模型是什么

一类回答「如何从噪声生成数据」的**生成模型**，分两步：

- **前向过程（加噪，固定）**：马尔可夫链把数据 `x_0` 逐步加高斯噪声，T 步退化为纯噪声 `x_T~N(0,I)`
- **反向过程（去噪，学习）**：训练神经网络把每步 `x_t` 还原为 `x_{t-1}`，采样时从纯噪声迭代还原

```text
前向（固定）：x_0 → x_1 → ... → x_T （数据 → 纯噪声）
反向（学习）：x_T → x_{T-1} → ... → x_0 （纯噪声 → 数据）
```

> 直觉：前向像墨水滴入清水扩散均匀；反向像学会「倒放」还原最初那滴。

<!--
前向不需学习是预设的，反向才是训练目标——这是扩散模型与 GAN 的本质区别。
-->

# 前向过程：逐步加噪

固定马尔可夫链，每步加一点高斯噪声：

```text
q(x_t | x_{t-1}) = N( √(1-β_t)·x_{t-1}, β_t·I )
β_t ∈ (0,1)：方差调度（DDPM 线性 1e-4 → 2e-2，T=1000）

闭式解（一步从 x_0 跳到任意 x_t）：
令 α_t = 1-β_t，ᾱ_t = ∏α_i
x_t = √ᾱ_t · x_0 + √(1-ᾱ_t) · ε ，  ε~N(0,I)
```

| 时间步 t | ᾱ_t | x_t 样子 |
| --- | --- | --- |
| t=0 | 1 | 原图 x_0 |
| t 小 | 接近 1 | 轻微噪声，能看清 |
| t 大 | 接近 0 | 几乎纯噪声 |
| t=T | ≈0 | 纯高斯噪声 |

> β_t 递增是为了让 ᾱ_T 尽快趋于 0，保证 x_T 是各向同性高斯。

<!--
闭式解是训练核心：给定 x_0 随机采 t 和 ε 直接算 x_t，无需跑 T 步前向。
-->

# 反向过程：学习去噪

拟合 `q(x_{t-1}|x_t)`（无法直接计算），用神经网络参数化：

```text
p_θ(x_{t-1}|x_t) = N( μ_θ(x_t,t), Σ_θ(x_t,t) )
μ_θ = (1/√α_t)·(x_t - (1-α_t)/√(1-ᾱ_t)·ε_θ(x_t,t))
                                              ↑ 网络预测噪声
```

**DDPM 关键简化**：不预测均值，让网络预测第 t 步加入的噪声 ε：

```text
L_simple = E[ ‖ε - ε_θ(√ᾱ_t·x_0 + √(1-ᾱ_t)·ε, t)‖² ]
```

> 这个简化损失去掉了 ELBO 加权项，效果反而更好，成为事实标准。

<!--
训练流程：采 x_0 → 随机采 t 与 ε → 闭式解算 x_t → 网络预测 ε → MSE 拉近。
-->

# U-Net：去噪网络架构

去噪网络 ε_θ 几乎都用 **U-Net**（带跳跃连接的编码器-解码器）：

```text
输入：x_t（图像）+ t（时间步）
  编码器（逐层降分辨率）+ 时间嵌入 t（正弦编码注入每层）
  瓶颈层
  解码器（逐层上采样，融合跳跃连接特征）
输出：与 x_t 同尺寸的预测噪声 ε_θ
```

**关键组件**：

- **时间嵌入**：正弦位置编码把 t 变向量加到每层（知道「哪个去噪阶段」）
- **跳跃连接**：编码器特征拼到解码器，保留高频细节（去噪关键）
- **自注意力**：中间分辨率层捕捉长程依赖（SD 在 16×16、8×8 加注意力）

> 不注入时间步 t 会导致网络无法区分去噪阶段，质量崩塌。

<!--
U-Net 的对称结构与跳跃连接是去噪任务的最佳架构选择。
-->

# 采样加速：DDIM

标准 DDPM 需 T=1000 步迭代，慢得难实用。DDIM 给出关键加速：

```text
思路：保持前向边缘分布 q(x_t|x_0) 不变，定义非马尔可夫前向
     → 反向采样步数大幅减少，模型无需重训

随机性控制 η ≥ 0：
  η = 0 → 完全确定性（DDIM 常用模式）
  η = 1 → 退化为标准 DDPM

用 η=0 跳跃式取子序列，20-50 步即达 DDPM 1000 步质量
```

**两大收益**：

1. **加速**：步数从上千降到几十，速度提升 20-50 倍
2. **确定性插值**：η=0 时输出固定，可在隐空间做语义插值

> 「训练好的模型直接换采样器」——所有加速方法（DPM-Solver、PNDM）都基于此思路。

<!--
DDIM 的最大价值是无需重训即可加速，且确定性采样支持隐空间插值。
-->

# 潜空间扩散：Stable Diffusion（LDM）

把扩散从像素空间搬到 VAE 潜空间，算力降几十倍：

```text
阶段 1（感知压缩）：VAE 编码器 E 把图像压成潜向量
  x → z = E(x)（如 64×64×4，压缩约 48 倍）
  解码器 D：z → x̂（重建），固定后不再训练

阶段 2（潜在扩散）：U-Net 在潜空间去噪
  ε_θ(z_t, t) 在 64×64×4 去噪（非 512×512×3）
  采样得 z_0 后用解码器 D 还原成图像
```

**为什么可行**：图像感知信息远低于像素冗余，VAE 压到低维几乎不丢感知信息。

> 让扩散能在消费级 GPU（8GB 显存）上运行，催生 SD/DALL·E/Midjourney。

<!--
LDM 是扩散模型走向大众的关键工程突破，两阶段解耦感知压缩与生成。
-->

# 条件机制：交叉注意力

LDM 通过在 U-Net 插入**交叉注意力层**接受文本等条件：

```text
文本 prompt → CLIP 文本编码器 → token 特征 τ（如 77×768）
U-Net 每分辨率层加交叉注意力：
  Q 来自潜特征 z_t，K/V 来自文本特征 τ
  CrossAttn(Q,K,V) = softmax(Q·K^T/√d)·V
```

让 U-Net 去噪时能「看到」文本条件，可接受任意条件（文本、布局、掩码、参考图）。

> 「cross-attention turns the model into a flexible generator」——LDM 论文。

<!--
交叉注意力是扩散模型多模态条件注入的通用接口，比拼接/相加更灵活。
-->

# Classifier-Free Guidance（CFG）

现代文生图标配，单一网络联合训练条件与无条件，推理时外插放大条件：

```text
训练：以一定概率（如 10%）把条件 c 替换为空 ∅
     同一网络既学 ε_θ(x_t,t|c) 又学 ε_θ(x_t,t|∅)

推理（引导采样）：
  ε̃ = (1+w)·ε_θ(x_t,t|c) - w·ε_θ(x_t,t|∅)
  w：引导强度，通常 1-15，文生图默认 7.5
```

**效果**：w 越大越贴合条件、质量越高，但多样性下降、可能过饱和。

> 无需额外分类器，一次前向算两次（带/不带条件），简单高效，类似 GAN 截断技巧。

<!--
CFG 直观体现质量-多样性权衡，是 SD 等文生图模型的默认配置。
-->

# 与分数模型、朗之万动力学统一

扩散模型并非孤立，与**分数模型**、**朗之万动力学**数学等价：

```text
分数函数：s(x) = ∇_x log p(x)
朗之万采样：x_t = x_{t-1} + (δ/2)·∇log p(x_{t-1}) + √δ·ε

DDPM 预测噪声 ε_θ 与分数的关系：
  s_θ(x_t,t) ≈ -ε_θ(x_t,t) / √(1-ᾱ_t)
  即预测噪声等价估计扰动分布的分数
```

**统一框架**（Song 2021）：DDPM、分数模型、朗之万动力学统一为连续时间 SDE：

```text
前向 SDE：dx = f(x,t)dt + g(t)dw （w 布朗运动）
反向生成对应反向 SDE（需分数函数）
```

> 不同离散化 → 不同模型（DDPM/分数模型/概率流 ODE），是现代扩散研究的数学基石。

<!--
这个统一框架让 DDIM、概率流 ODE、各种加速采样器都能在同一理论下推导。
-->

# Latent Consistency Models（LCM）

把扩散蒸馏成**几步生成**的一致性模型，逼近 GAN 速度：

```text
核心：训练一致性函数 f_θ(z_t, t) → z_0
     要求沿同一扩散轨迹 f_θ(z_t,t) = f_θ(z_{t'},t')

LCM = 在 LDM 潜空间做一致性蒸馏
     用 Stable Diffusion 作教师，蒸馏出 1-4 步学生
     结合 CFG 实现 1-4 步高质量文生图（vs 标准 SD 20-50 步）
```

**意义**：让扩散在「质量-速度」权衡上逼近 GAN，同时保留训练稳定性与可控性。

> 后续 LCM-LoRA 让加速可插拔复用，是 2023 年扩散加速里程碑。

<!--
LCM 是扩散蒸馏方向代表，解决了扩散采样慢的最大短板。
-->

# 反模式（生产坑）

1. **像素空间训大图扩散**：512×512 算力爆炸，应用 LDM 潜空间
2. **采样不用加速器**：直接跑 DDPM 1000 步慢不可用，必用 DDIM/DPM-Solver/LCM
3. **CFG 强度设错**：w=0 与条件无关，过大（如 30）过饱和怪异，默认 7-9
4. **方差调度选错**：β_t 不递增或 ᾱ_T 不趋于 0，x_T 非纯高斯，采样失败
5. **混淆预测目标**：网络应预测噪声 ε（DDPM），非直接预测 x_0 或均值
6. **忽视时间嵌入**：U-Net 不注入 t，无法区分去噪阶段，质量崩塌

> 生产级扩散需精细的方差调度、潜空间扩散、CFG，但训练-采样核心逻辑是这六条。

<!--
这六条对应明确的修复方案，是生产环境最常见的崩溃点。
-->
