# 掘金是什么

字节跳动旗下的中文技术内容分享与交流平台

- **纯技术垂直**：定位聚焦中文开发者，受众精准
- **字节流量加持**：2020 被字节收购，算法分发强
- **多元形态**：文章 + 沸点 + 课程 + 直播
- **个性化推荐**：字节系算法按兴趣分发
- **掘力值 / 创作等级**：游戏化激励体系

> 2015 上线，中文技术内容沉淀与个人品牌首选

# 写第一篇技术文章

「写文章」→ Markdown 编辑器

**文章结构**

- 标题：含关键词利于推荐
- 封面图：有封面推荐权重高
- 摘要：一句话进推荐流
- 分类：前端 / 后端 / AI ...
- 标签：**最多 3 个**，相关具体
- 正文：Markdown + 代码 + 公式

编辑器：实时预览 / 代码高亮 / KaTeX / 草稿自动保存

# 标签优化

标签是掘金分发的重要信号（最多 3 个）

**选择原则**

1. 大标签带流量：前端 / 后端 / AI
2. 小标签带精准：React / Vue / Go
3. 细分标签带场景：Webpack / 源码
4. 不堆砌：无关标签会被降权

| 文章类型 | 标签示例 |
|---|---|
| React Hooks 深度 | 前端 / React / JavaScript |
| Vue 3 源码解析 | 前端 / Vue.js / 源码 |
| 大模型 RAG 实战 | AI / 后端 / Python |

> 3 个标签组合「大 + 小 + 场景」

# 推荐算法与曝光

掘金推荐基于字节系算法

| 信号 | 权重 |
|---|---|
| 点击率（标题 + 封面） | 高 |
| 阅读完成率 | 高 |
| 点赞率 / 评论收藏率 | 高 / 中高 |
| 负反馈（举报 / 跳出） | 负 |

**优化要点**

- 标题与封面决定点击率（避免标题党）
- 开头 3 段决定留存，段落短、小标题多

> 结尾抛问题拉评论率

# 掘力值与创作等级

掘力值衡量创作者活跃度，决定创作等级

| 等级 | 大致掘力值 |
|---|---|
| LV1 | 新注册 |
| LV2-LV5 | 入门到稳定贡献 |
| LV6-LV8 | 资深创作者到头部 KOL |

等级解锁：专栏、收益、官方资源扶持、年度榜单资格

**年度创作者影响力榜单**

- 每年评选「年度影响力创作者」
- 上榜获官方流量扶持 + 品牌背书 + 商业合作

> 上榜是中文技术圈认可的荣誉

# 字节收购（2020）的影响

2020 被字节跳动收购后的变化

**正面影响**

- **流量加持**：字节系导流（抖音 / 今日头条技术向）
- **算法升级**：复用字节推荐算法，分发更精准
- **资源投入**：产品迭代加速，XDC 大会规模扩大
- **商业机会**：字节生态合作

**潜在风险**

- **战略依赖**：受字节整体节奏影响
- **审核收紧**：字节系审核标准
- **不确定性**：字节战略调整时定位可能变化

> 字节流量 + 算法是掘金增长的核心引擎

# 课程与小册变现

掘金的主要变现路径

**掘金小册**

- 系统化付费专栏（10-30 篇连载）
- 作者与平台分成
- 需达创作等级 + 通过审核
- 适合深度体系化内容

**其他变现**

- 引流到自有产品（课程 / SaaS / 咨询）
- 头部 KOL 获厂商品牌赞助
- 年度榜单加持后商业机会增多

> 文章本身无类似 Medium 的稳定分成
